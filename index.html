BEFORE YOU BEGIN

Use VIBES after AI use is permitted.

Use this checklist after you have decided why you are using AI and confirmed that its use is permitted. Before AI-generated or AI-assisted content is finalized, shared, or put into practice, review each item, including but not limited to: clinical documentation, diagnostic reports, treatment plans, progress notes, session reports, and/or client-centered academic assignments such as case studies.

01 · Review each statement

Mark Met only when every applicable part of the statement is satisfied.

02 · Handle exceptions carefully

Use N/A only when an item does not apply. N/A counts as reviewed and is recorded separately.

03 · Resolve concerns

If an applicable item is not met or is unclear, pause to verify, revise, or seek guidance before using the work.

ABOUT THIS TOOL

Evidence-informed, with clear limits.

The VIBES AI Checklist is a 16-item tool organized into Validity, Integrity, Bias, Evidence, and Safety. Initial content-validity evidence relates to Version 1 item statements. Version 2.1 includes subsequent wording revisions that have not been re-rated. This interactive implementation has not been independently validated.

All checklist statements and rationales are reproduced from the supplied Version 2.1 document. The digital response options Met / Not met / Unclear / N/A are an interface adaptation of the original checkbox and N/A instructions, not a separately validated response scale.
